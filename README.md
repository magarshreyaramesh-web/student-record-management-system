# Student Record Management System

## 📌 Project Overview

The Student Record Management System is a Python-based mini project developed to manage student academic records efficiently.

The system provides a simple menu-driven interface that allows users to add, display, search, update, and delete student records.

## 🎯 Objectives

- Maintain student records in an organized way.
- Add and manage student information.
- Search for a particular student.
- Update existing student records.
- Delete student records when required.
- Calculate average marks.
- Find the highest-scoring student.
- Display students according to their department.
- Count the total number of students.

## ✨ Features

The system provides the following operations:

1. Add Student
2. Display Students
3. Search Student
4. Update Student
5. Delete Student
6. Calculate Average Marks
7. Find Highest Scorer
8. List Students by Department
9. Count Students
10. Exit

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Python Dictionary
- Conditional Statements
- Loops
- Functions / Basic Python Programming Concepts

## ▶️ How to Run

### Using Jupyter Notebook

1. Download or clone this repository.
2. Open `student_record_management_system.ipynb` in Jupyter Notebook.
3. Run the notebook cells.
4. Follow the menu displayed by the program.
5. Enter the required student information.

### Using Google Colab

The notebook can also be opened in Google Colab and the code cells can be executed there.
